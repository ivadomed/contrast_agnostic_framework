# 0_raw_open-ms — provenance (PRISTINE, do not modify)

Source: muschellij2/open_ms_data (GitHub), `cross_sectional/coregistered_resampled/`.
Underlying data: Lesjak et al., "A Novel Public MR Image Dataset of MS Patients With
Lesion Segmentations Based on Multi-rater Consensus", Neuroinformatics 2018. CC-BY.

30 patients. Per patient: FLAIR, T1W, T2W (all co-registered to FLAIR, N4 bias-corrected,
1mm isotropic, 154x240x240, LPS), consensus_gt.nii.gz (binary MS-lesion mask in FLAIR
space), brainmask.nii.gz. Downloaded 2026-06-30.
