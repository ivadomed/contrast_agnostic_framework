All methods share one nnU-Net~\cite{isensee2021nnunet} configuration; only
the input augmentation differs. Nothing below is tuned per dataset.

\paragraph{Training schedule.} 3D full-resolution nnU-Net, SGD with Nesterov
momentum $0.99$, initial learning rate $10^{-2}$ with the nnU-Net
\texttt{polyLR} decay, $250$ mini-batches per epoch, combined Dice and
cross-entropy loss, deep supervision on. Patch size, spacing and batch size
are whatever the nnU-Net planner selects for that dataset, identically for
every method. The epoch budget is fixed per dataset and shared by all methods
on it: $2500$ (BraTS-GLI), $2000$ (ON-Harmony, Open-MS), $1000$ (ToothFairy2,
I-SPY2) and $200$ (CHAOS, Pelvis); Spine was trained on a separate pipeline.
Each method is trained as three models on three train/validation folds, all
scored on the same held-out test set; folds are the same across methods.

\paragraph{PALETTE-Aug hyper-parameters.} Set once and never tuned per dataset:
$k$-means class count drawn per sample from $\{2,\dots,6\}$, skipped in
favor of a single global remap with probability $0.10$; Voronoi
sub-parcellation of each intensity class with probability $0.60$ (else left
as one region); signed affine coefficient $\alpha \in \pm U(0.5, 2.0)$
applied per sub-region as in \cref{eq:affine} (always applied, to whatever
partition results from the $k$-means/Voronoi steps); per-label affine
decoupling applied independently per label with probability $0.5$ (skipped
for any label with under $4$ foreground voxels in that sample); Gaussian
blur $\sigma$ drawn from $\{0,0,0,0.3,0.5,0.8\}$, applied twice (after the
region-level and after the label-level remap), so applied half the time at
each point. The transform is applied on the GPU, on-the-fly, to a fixed
$50\%$ of training
iterations (\emph{train050}); the remaining half of iterations use the
un-transformed real image.

\paragraph{Validation-time configuration.} \emph{val000} (the configuration
reported in the main paper) applies no synthetic contrast to the validation
split, matching every competing method and keeping model selection
like-for-like. \emph{val100} applies PALETTE-Aug to the entire validation split;
it is reported in \cref{sec:suppl-val100}.

\paragraph{Baseline configurations.} Both SynthSeg variants run through
Auglab's GPU implementation of the SynthSeg generator, with uniform intensity
priors and with the generator's own spatial and flip steps disabled (the
pipeline's spatial augmentation is shared by all methods). They receive each
task's training label map; SynthSeg-EM additionally subdivides it on the fly
by expectation-maximization clustering of the image ($2$ sub-regions per
foreground label, $3$--$10$ for the background, $20$ iterations), where the
original work precomputes these maps~\cite[\S5.4]{billot2023synthseg}. Each
sub-region then receives a randomly sampled intensity, as in SynthSeg. Both
SynthSeg variants and SRCSM synthesize on every training iteration because
their original papers train that way, so we keep that setting when running
them; PALETTE-Aug synthesizes on $50\%$ of iterations. SRCSM is a training-time
augmentation only: no test-time intensity matching is applied, and every
method is predicted with the same nnU-Net predictor, without test-time
augmentation. SRCSM and Auglab otherwise use their published default
configurations. No competing method was re-tuned in our favor, and all use
the same folds, schedule and epoch budget as above.

\paragraph{Compute.} Training was performed on NVIDIA L40S and H100 GPUs. A
single fold costs from under an hour (CHAOS, $200$ epochs) to roughly three
days (BraTS-GLI, $2500$ epochs); the full study is dominated by the six
methods $\times$ eighteen settings $\times$ three folds of the main comparison,
plus the sixteen ablation ladders of \cref{subsec:e-ablation}.
